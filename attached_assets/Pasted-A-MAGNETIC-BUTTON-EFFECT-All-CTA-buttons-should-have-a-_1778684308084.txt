A. MAGNETIC BUTTON EFFECT
All CTA buttons should have a magnetic pull effect — when mouse gets close, button slightly moves towards cursor:

buttons.forEach(btn => {
  btn.addEventListener('mousemove', (e) => {
    const rect = btn.getBoundingClientRect();
    const x = e.clientX - rect.left - rect.width / 2;
    const y = e.clientY - rect.top - rect.height / 2;
    btn.style.transform = `translate(${x * 0.3}px, ${y * 0.3}px)`;
  });
  btn.addEventListener('mouseleave', () => {
    btn.style.transform = 'translate(0, 0)';
    btn.style.transition = 'transform 0.5s ease';
  });
});

When hovering over project cards, image appears to ripple/distort slightly using CSS filter:

  filter: brightness(0.85) contrast(1.05);
  transform: scale(1.06);
  transition: all 0.7s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}

G. PAGE TRANSITION between pages
When clicking any internal link, the page fades out to cream colour, then new page fades in:

Before navigating: overlay div fades in (opacity 0 → 1, cream background)
On new page load: overlay fades out (opacity 1 → 0)
Duration: 0.4s each way

Add overlay div at top of body:
<div id="page-transition-overlay"></div>

CSS:
#page-transition-overlay {
  position: fixed; inset: 0;
  background: var(--color-cream);
  z-index: 99999;
  opacity: 0;
  pointer-events: none;
  transition: opacity 0.4s ease;
}

I. SCROLL PROGRESS BAR
Thin gold line at the very top of the page (below announcement banner) that fills from left to right as user scrolls down:

#scroll-progress {
  position: fixed;
  top: 0; left: 0;
  height: 2px;
  background: var(--color-gold);
  z-index: 9999;
  width: 0%;
  transition: width 0.1s linear;
}

window.addEventListener('scroll', () => {
  const scrolled = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
  document.getElementById('scroll-progress').style.width = scrolled + '%';
});
