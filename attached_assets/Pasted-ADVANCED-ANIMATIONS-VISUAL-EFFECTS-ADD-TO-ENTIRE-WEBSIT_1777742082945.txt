Using GSAP or vanilla JS counter:
function animateCounter(el, target) {
  let count = 0;
  const increment = target / 80;
  const timer = setInterval(() => {
    count += increment;
    if (count >= target) { el.textContent = target + "+"; clearInterval(timer); }
    else { el.textContent = Math.floor(count); }
  }, 25);
}

11. SMOOTH PAGE SCROLL (Lenis)
Replace browser default scroll with buttery smooth scroll:
Add Lenis smooth scroll library:
<script src="https://cdnjs.cloudflare.com/ajax/libs/lenis/1.0.42/lenis.min.js"></script>

Initialize:
const lenis = new Lenis({ duration: 1.4, easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), smooth: true })
function raf(time) { lenis.raf(time); requestAnimationFrame(raf); }
requestAnimationFrame(raf)

Connect with GSAP ScrollTrigger:
lenis.on('scroll', ScrollTrigger.update)
gsap.ticker.add((time) => { lenis.raf(time * 1000) })

This makes the ENTIRE website scroll feel like butter — huge premium upgrade
